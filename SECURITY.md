# Security Policy

## Supported Development Line

The `main` branch is the active development line for The Last Settlement.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability that exposes credentials, private data, or an exploitable security weakness. Report it through GitHub's private vulnerability reporting or contact the DPN Technology maintainers privately.

Include the affected file or workflow, reproduction steps, impact, and any suggested mitigation.

## Security Baseline

The repository enforces pinned GitHub Actions, repository security auditing, workflow scanning, dependency review, OpenSSF Scorecard analysis, and policy checks. High-risk GDScript process-execution and dynamic-evaluation APIs require explicit review before being introduced.
